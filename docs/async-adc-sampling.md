# FOC 异步 ADC 采样记录

更新时间：2026-09-10

## 目的

记录当前电流环中 ADC 采样与 PWM/控制时刻之间的关系，避免把“ADC 连续采样 + 软件时间戳对齐”误认为 PWM 同步采样。本文对应当前 `simple_foc_sh` 工作区的代码状态。

## 当前实现

- PWM：20 kHz，MCPWM 上下计数模式。
- 电流环：每 4 个 PWM 周期运行一次，控制周期为 200 us（5 kHz）。
- ADC：ESP32 ADC continuous DMA，自由运行，配置采样频率 200 kHz。
- 通道：U 相 ADC1_CH0/GPIO36，V 相 ADC1_CH3/GPIO39；W 相通过 `iw = -(iu + iv)` 重构。
- DMA 帧：`CURRENT_ADC_FRAME_SIZE_BYTES=80`。经典 ESP32 的一个逻辑结果占 4 字节，因此一帧约 20 个结果，约包含 U/V 各 10 个结果，覆盖约 100 us、约 2 个 PWM 周期。
- 电流值：DMA 任务对一帧内的 U/V 结果求平均，使用帧中点时间戳写入历史帧；电流环在控制时刻读取不晚于该时刻的已完成帧。
- 角度：当前调试阶段关闭速度预测补偿，Park 和逆 Park 使用同一测量电角度。

## 关键结论

当前实现不是“PWM 完成后采一次 ADC”。ADC 与 PWM 没有硬件触发同步关系，ADC 可能在 PWM 周期的不同相位采到数据；80 字节帧平均可以降低噪声，但同时引入帧中点延迟和相位不确定性。

理想的电流环采样顺序是：PWM 到固定采样相位 → 等待开关瞬态/死区结束 → 在固定相位采 U/V → Clarke/Park → PI → 更新下一 PWM。这里的“固定相位”比“PWM 完成后”更重要。

## 2026-09-10 最新日志证据

日志中的数据格式为：

```text
FOC_DATA,timestamp,id_ref_mA,iq_ref_mA,id_mA,iq_mA,vd_mV,vq_mV,speed,current_age_us,angle_age_us,fault
```

按 `id_ref_mA` 分组统计该次日志：

| 设定 Id | 最后窗口实际 Id | Iq | 最大 current_age_us | fault |
|---:|---:|---:|---:|---:|
| 0 mA | 平均 9.3 mA，-3～23 mA | 平均 -0.9 mA，-17～15 mA | 401 us | 0 |
| 100 mA | 平均 93.9 mA，56～124 mA | 平均 0.4 mA，-8～11 mA | 401 us | 0 |
| 200 mA | 平均 152.2 mA，46～254 mA | 平均 0.5 mA，-18～21 mA | 428 us | 0 |

这说明：

1. 目标值已经正确进入下位机，日志中确实出现了 0、100、200 mA 的 `id_ref`。
2. 200 mA 时没有触发 1 A 保护，也没有电压矢量饱和；`vd` 大约为 0.9～1.7 V，而 PI 输出限幅为 ±6 V。
3. Iq 仍接近 0，说明这次主要问题不是明显的 d/q 轴串扰或目标值传输错误。
4. 200 us 的控制周期下，`current_age_us` 出现 400 us 左右，说明部分控制计算使用了超过一个控制周期以前的 ADC 帧。这个延迟会直接降低 PI 的相位裕量，并造成高目标电流下的波动/欠跟随。

## 当前判断

`80` 字节帧比此前 `160` 字节帧更合适，已经避免了此前的大幅失控；但它只是降低了平均窗口长度，不等于完成了 PWM 同步采样。当前 200 mA 的欠跟随不能单独归咎于 PI 参数，必须同时处理：

- ADC 自由运行造成的采样相位变化；
- 帧平均带来的测量延迟；
- DMA 任务若出现积压时，逐帧消费通知可能继续处理旧帧。

因此在采样时序没有收敛前，不应继续盲目增大 PI 增益。否则可能把旧反馈造成的延迟放大成振荡。

## 后续调试顺序

1. 在下位机记录 ADC 帧序号、帧中点时间、控制 tick 时间、`current_age_us` 和通知/帧积压情况。
2. 让电流环优先使用最新完整 ADC 帧，明确丢弃已经失去控制价值的旧帧，并验证不会因丢帧造成时间戳错配。
3. 重新做 `Id: 0 → 100 → 200 mA` 阶跃，每个点保持至少 5 s；同时确认 `Iq` 仍接近 0、`fault=0`、电流年龄基本不超过一个 200 us 控制周期。
4. 采样链路稳定后，再单独调 Id PI；最终固定扭矩测试使用 Iq，Id 只保持为需要的励磁电流。
5. 如果仍要求更高带宽，再评估经典 ESP32 上可用的底层 PWM 相位触发 ADC 方案；当前公开的高层 ADC continuous 接口没有直接提供 MCPWM→ADC 的同步采样配置。
